# Network Engineering Projects

A collection of hands-on networking projects focused on network design,
configuration, troubleshooting, security, and automation.

These projects are developed as part of my learning journey toward
becoming a Network Engineer.

## About This Repository

This repository documents practical networking exercises and projects
using tools such as Cisco Packet Tracer, Wireshark, Linux, and Python.

Each project includes its objectives, topology or architecture,
configurations, testing evidence, and lessons learned.
